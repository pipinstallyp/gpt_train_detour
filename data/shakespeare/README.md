# Tiny Shakespeare

Exact Runpod corpus bytes, originally obtained from https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt . Author: William Shakespeare; source distribution: Andrej Karpathy. The underlying Shakespeare works are public domain. The model uses the first 90% of characters for training and the final 10% for validation. See manifest.json for the content hash.
